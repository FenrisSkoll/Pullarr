Mega

Mega is a file sharing service that supports end-to-end encrypted downloads, which Pullarr makes use of.

By default, you are limited to downloading around 5GB of files per day from Mega. There are no download speed constraints.

Mega offers free and paid accounts that come with higher limits for downloading files. Pullarr is able to download files using an account to take advantage of these higher limits (i.e. being able to download more than 5GB per day). If you have a Mega account, it's advised to enter the credentials below so that Pullarr can take advantage of it's premium features. Also make sure to set Mega high in the service preference list, so that Pullarr will prefer using it.

MediaFire

MediaFire is a file sharing service from which Pullarr can download files.

MediaFire does not limit how much you can download per day.

WeTransfer

WeTransfer is a file sharing service from which Pullarr can download files.

WeTransfer does not limit how much you can download per day.

Pixeldrain

Pixeldrain is a file sharing service from which Pullarr can download files.

By default, you can download up to 6GB of files at full speed per day from Pixeldrain. After that limit is reached, download speed is reduced to 1MB/s.

Pixeldrain offers paid subscription plans that remove this speed limit. Pullarr is able to download files using an account to take advantage of these higher limits (i.e. download more than 6GB per day at full speed). If you have a Pixeldrain account, it's advised to enter the credentials below so that Pullarr can take advantage of it's premium features. Also make sure to set Pixeldrain high in the service preference list, so that Pullarr will prefer using it.

GetComics

GetComics is a website that offers a vast amount of downloads for comics. Pullarr can search this website to find downloads for the volumes in your library. The comics can be downloaded via multiple services. Pullarr has built-in support for almost all these services.

When downloading directly from the servers of GetComics (instead of using an external service), the download speed will be significantly reduced 400MB into the download. This behaviour is set up by the owner of the website, is intentional, and is not planned to be removed.

Also, most often on Wednesday and Thursday, the site is very busy so the downloads speed goes down a lot. Preferring external services in the service preference list is advised in order to avoid this.
